# Basic CI/CD

Разработка простого **CI/CD** для проекта на Си. Сборка, тестирование, развертывание.

## Introduction

В данном проекте реализован базовый пайплайн CI/CD для Си-проекта 
(утилиты `cat` и `grep` из проекта SimpleBashUtils). Настроен gitlab-runner, 
автоматизированы этапы сборки, проверки кодстайла, запуска интеграционных тестов, 
развертывания на удаленном сервере и отправки уведомлений.

## Part 1. Настройка gitlab-runner

- Поднята виртуальная машина **Ubuntu Server 24.04 LTS**.
- Скачан и установлен **gitlab-runner**.
- Gitlab-runner запущен и зарегистрирован для использования в текущем проекте (DO6_CICD) с использованием URL и токена.

## Part 2. Сборка

- В файл `.gitlab-ci.yml` добавлен этап CI для запуска сборки через Makefile из проекта.
- Артефакты, полученные после сборки, сохранены в произвольную директорию со сроком хранения 30 дней.

## Part 3. Тест кодстайла

- Написан этап CI, запускающий скрипт проверки кодстайла (`clang-format`).
- В случае непрохождения кодстайла пайплайн завершается с ошибкой («фейлится»).
- Вывод утилиты `clang-format` отображается в пайплайне.

## Part 4. Интеграционные тесты

- Написан этап CI для запуска интеграционных тестов (использованы готовые тесты для SimpleBashUtils или написаны собственные для code-samples).
- Этап запускается автоматически только при условии успешного прохождения сборки и теста кодстайла.
- Если интеграционные тесты не проходят, пайплайн завершается с ошибкой.
- В пайплайне отображается вывод об успешном или проваленном прохождении тестов.

## Part 5. Этап деплоя

- Поднята вторая виртуальная машина **Ubuntu Server 24.04 LTS** (продакшн).
- Написан этап CD для развертывания проекта на второй виртуальной машине.
- Этап запускается вручную при условии успешного прохождения всех предыдущих этапов.
- Написан bash-скрипт, который при помощи `ssh` и `scp` копирует артефакты сборки в директорию `/usr/local/bin` второй виртуальной машины.
- В случае ошибки при деплое пайплайн завершается с ошибкой.
